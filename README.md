# Chartman2-fr

Bienvenue sur **Chartman2-fr**, le dépôt du site web personnel de Christophe Hartmann. Ce site sert à la fois de vitrine personnelle et de plateforme de partage d’articles techniques, retours d’expérience et projets liés à l’informatique.

## 🎯 Objectifs du site

* Présenter mon profil, mes compétences.
* Publier des articles détaillés sur divers sujets techniques : développement, infrastructures, DevOps, et autres domaines liés au numérique.
* Proposer des guides, tutoriels et notes pratiques basés sur mes expériences.

## 🧰 Technologies utilisées

Le site est construit autour des technologies modernes du web. Selon l’évolution du projet, il peut inclure :

* **Nuxt 3 / Vue.js** pour la partie frontend.
* **Node.js** pour certains scripts et outils.
* **Docker** pour faciliter le déploiement et les environnements.
* Divers services et outils selon les besoins (CI/CD, automatisation, etc.).

## 📂 Structure du dépôt

* `components/` - Composants Vue réutilisables dans l’ensemble du site.
* `composables/` - Fonctions réutilisables
* `middlewares/` - Middlewares utilisés pour contrôler l’accès aux pages
* `layout/` - Gabarits de pages 
* `plugins/` - Plugins Nuxt côté client/serveur
* `pages/` - Pages du site
* `public/` : Contenus statiques (images, icônes, fichiers publics).
* `content/` : Articles, billets et contenus rédactionnels.
* `README.md` : Ce document.
* `LICENSE` : Licence du projet (MIT).

## ✍️ Articles et publications

Le site contient ou contiendra :

* Des articles techniques approfondis.

## 🚀 Développement

Pour installer et lancer le projet localement :

### Setup

### ⚙️ Installation des dépendances

Assurez-vous d’installer les dépendances

```bash
# pnpm
pnpm install
```

### 🖥️ Serveur de développement

Démarrer le serveur de développement sur `http://localhost:3000`

```bash
# pnpm
pnpm run dev
```

### 🏗️ Mode production

Construire l’application pour la production

```bash
# pnpm
pnpm run build
```

### 👀 Prévisualisation locale

Prévisualiser localement la version de production

```bash
# pnpm
pnpm run preview
```
